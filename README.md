## The Problem we're Solving

> "customers call to book,but we're busy cutting hair, so calls go unattended. people walk in,see five people"
> waiting and leave. meanwhile at 2pm my barbers sit idle. we keep booking in a paper diary and end up with double booking every week"
> **Joseph, owner, Great cut Barbershop,kilimani, Nairobi**

## Features

**For Customers**
- Browse **Services** with prices(KES) and durations, and **barbers** with their speciality.
- Click a chair on the **shop floor plan**

** For Barbershops**
- **Dashboard** with today's stats,schedules (status badges),weekly availablity and an update-hours form.

**Everywhere**
- Mobile-first, responsive system
- **Dark Mode** toggle (remembers your choice)

### Installation

```bash
# 1.Get the code
git clone https://github.com/justinjnr23-hub/Great-cut.git
cd Great-cut

# open in vs code
code .
```
3. in VS Code,right-click `index.html` and choose **Open with Live Server**
4. **Your should see the Great cut home page at `http://127.0.0.1:5000`. Try booking a cut on the `book.html`.
